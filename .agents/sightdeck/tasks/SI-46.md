# Reduce hero top-panel large padding

The homepage hero top-panel text column uses `p-4 sm:p-6 lg:p-8`. On large screens that is 32px; drop it to `lg:p-6` (24px) so it matches `sm`.

Leave the newsletter card (`p-6 lg:p-8`) unchanged unless the same class string is requested.
