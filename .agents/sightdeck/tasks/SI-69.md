# Check Medusa mail sending setup

## Goal

Confirm whether Medusa can actually send transactional mail (OTP, cadeaubon), or only log it.

## Finding

Code is ready. Nothing is sending.

- Wired senders: OTP (`customer-otp`) and cadeaubon (`gift-card-purchased`), via SMTP (`src/providers/smtp`) or SendGrid. SMTP wins if both env sets exist. Bodies include `text` and `html`.
- Local `medusa/.env` and staging `~/app/medusa/.env` have **no** `SMTP_*` or `SENDGRID_*`. PM2 has none either.
- Staging already has Postfix on `127.0.0.1:25` (banner `stag1.vrijeacademie.nl ESMTP`). A local SMTP handshake accepted `MAIL FROM` / `RCPT TO`. Not used, because env is unset.
- Notification provider in the staging DB is only `local` (logs, does not send).
- Not implemented: order confirmations, waitlist mail, admin-generated OTP (shown in Admin only).

To actually send on staging: set `SMTP_HOST=127.0.0.1`, `SMTP_PORT=25`, `SMTP_SECURE=false`, `SMTP_FROM=noreply@vrijeacademie.nl` in `~/app/medusa/.env`, then PM2 reload. Inbox delivery still depends on Postfix relay + SPF/DKIM for the From domain.
