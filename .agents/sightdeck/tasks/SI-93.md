# Fix: Could not delete all payment sessions

## Goal

Find why Medusa returns `{"type":"unexpected_state","message":"Could not delete all payment sessions"}` on an order, and fix or document the cause.

## Cause

Medusa `deletePaymentSessionsWorkflow` → `validateDeletedPaymentSessionsStep`. Triggered when starting a new payment session (retry / other method) or when the cart total changes (gift card) so leftover sessions are deleted.

`@variablevic/mollie-payments-medusa` `cancelPayment` does `const { id } = input.data` **outside** its try/catch. Missing `data` or a failed Mollie GET throws; Medusa then refuses to drop the session and checkout stays blocked. Klarna `deletePayment` rethrew the same GET errors.

## Fix

- Klarna: `safeCancelMolliePayment` (never throws; skip cancel for paid/canceled/expired/failed)
- Plugin: `patchMolliePluginDeletePayment()` from `medusa-config.ts`
- Storefront maps the API message to Dutch copy
