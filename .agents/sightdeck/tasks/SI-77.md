# Skip STARTTLS for local Postfix

## Goal

OTP and cadeaubon mail via localhost Postfix must not fail on the snakeoil STARTTLS cert.

## Approach

Set nodemailer `ignoreTLS` for loopback hosts (`127.0.0.1`, `localhost`, `::1`), overridable with `SMTP_IGNORE_TLS`. Document it. Tests for the resolver.

## Shipped

`parseIgnoreTls` defaults true on loopback; `SMTP_IGNORE_TLS` overrides. SMTP provider passes `ignoreTLS` to nodemailer. Docs: CUSTOMER_AUTH, DEPLOYMENT, `.env.template`. Staging still needs a deploy before OTP mail works.
