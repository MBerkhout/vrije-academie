# Match checkout thumbnails to product tiles

Checkout line thumbnails (`OrderSummaryThumbnail`) were 56×56. Cart rows and product tiles use a 4:3 crop.

The same component is used on inloggen, betaling, the thank-you page, and account order lines. It now uses the cart thumbnail frame: 4:3, 64px tall, 80px from the `md` breakpoint.
