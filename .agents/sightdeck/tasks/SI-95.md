# Hide Mollie Checkout payment method

The storefront payment step lists Medusa providers, including `pp_mollie-hosted-checkout_mollie` labelled **Mollie Checkout**. That provider is Mollie’s catch-all hosted page. Every other tile already creates a Mollie session, so showing it as a method is redundant and confusing.

## Approach

Keep the provider registered in Medusa (seed / Admin) so existing sessions and Salesforce mapping still work. Hide it on the storefront:

- Filter it out in `PaymentMethodTiles` (same as `pp_system_default`)
- Skip it when auto-selecting a default method in `CheckoutPaymentForm`

## Docs

Note in `frontend/docs/CHECKOUT.md` and `medusa/docs/PAYMENT-MOLLIE.md` that hosted checkout is enabled in Medusa but not shown as a tile.
