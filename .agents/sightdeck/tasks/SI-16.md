# Validate phone number by digit count

## Goal

Phone fields that already use `validateAccountField('phone')` should reject values with too few or too many digits, not only illegal characters.

## Rule

Count digits only (ignore `+`, spaces, dashes, parentheses). Empty stays optional except where the form already requires a number (waitlist). Accept **8–15** digits (NL/BE/DE plus E.164). Keep the existing invalid copy.

## Surfaces

Register (`LoginForm`), checkout guest/profile, account gegevens, waitlist modal.
