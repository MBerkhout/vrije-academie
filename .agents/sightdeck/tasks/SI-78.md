# Hide VAthuis filter on agenda

## Goal

Show the **VAthuis** availability checkbox only on Ons aanbod. Agenda should keep Online / Op locatie and ignore leftover `delivery_type=pre_recorded` query params.

## Notes

Agenda reuses `PlpFilterSidebar`, which currently always lists `pre_recorded` as VAthuis. VAthuis is on-demand and has no agenda occurrences, so the option is misleading there.
