# Medusa SMTP vs SendGrid

## Question

Can Medusa send OTP (and other transactional mail) via the staging server’s SMTP instead of SendGrid?

## Answer

Not out of the box. Medusa has no first-party SMTP provider. The app currently registers SendGrid only when `SENDGRID_API_KEY` is set. Only one notification provider can own the `email` channel.

SMTP is doable: a small custom provider (`nodemailer`) under `src/providers/`, switched by env (`SMTP_HOST` vs `SENDGRID_API_KEY`). Prefer that over a third-party plugin.

Do not send OTP through local postfix/sendmail on the VPS unless SPF/DKIM/PTR are in place — inbox delivery will be poor. Use the organisation’s existing authenticated SMTP (same host the current site uses) instead.
