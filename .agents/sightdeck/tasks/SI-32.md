# Fix PDP gallery credits (WD-041)

## Goal

PDP gallery credits (Salesforce `Image_N_Source__c`) must show readable text: decoded characters, full credit, no mojibake. Title and body are already correct; only the credit field (and its alt text) is wrong.

## Issues

1. **Double-escaped HTML** — ~95/522 credits show literal entities (`Ren&eacute;`, `replica&#39;s`, `in&nbsp;Scottish`). Same value is used for alt. Cause: Salesforce already stores entities; `escapeHtml` turns `&` into `&amp;`. Decode once in caption rendering; HTML overlay and alt both pick it up.
2. **Truncation** — `line-clamp-4` cuts ~19/522 credits, usually the museum name. Example: `sail-rome` misses "Allard Pierson Museum, Amsterdam". Show the full credit (no clamp).
3. **Mojibake** — `havenscÃ¨ne` (`sail-rome`), `FranÃ§ois` (`de-winter-van-vivaldi`). UTF-8 read as Latin-1. Repair in the same caption normalizer.

## Out of scope

Gallery image counts (33/200 PDPs with no images, 30 with 1–3) are not part of WD-041.

## Approach

Normalize in `formatPdpGalleryCaption`: decode HTML entities, repair mojibake, then split on ` | `. Keep `em`/`strong` for the overlay; strip tags for alt.

## Examples

- `college-ren-magritte`, `lezing-100-jaar-dada`, `achtdaagse-vliegreis-naar-het-heilige-land`
- `sail-rome`, `de-winter-van-vivaldi`

## Result

Decoded in `formatPdpGalleryCaption` (entities + mojibake). Removed `line-clamp-4`. Verified on Magritte, Dada, Heilige Land, Sail Rome.
