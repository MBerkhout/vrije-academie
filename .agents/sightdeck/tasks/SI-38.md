# Agenda search returns no results for Rondleiding rijks

## Goal

`/agenda?q=Rondleiding+rijks&sort=relevance` should return matching agenda occurrences (e.g. Rijksmuseum tours).

## Why

A real query that should match events currently yields an empty listing.

## Approach

Trace the agenda search path (`GET /store/agenda`, OpenSearch vs in-memory fallback, relevance ranking) and reproduce with the same query.

## Finding

OpenSearch **was running** inside Docker (`medusa-opensearch` Up, `va-search` has 453 docs, query matches Rijksmuseum tours). Host `localhost:9200` was not published (`docker ps` showed empty PORTS / empty Networks). Medusa then used in-memory substring matching of the **full** query, so `Rondleiding rijks` missed `Rondleiding Hoogtepunten van het Rijksmuseum`.

Recreated the container (`docker compose up -d --force-recreate opensearch`). Port `9200` is published again; the agenda query returns 173 rows.
