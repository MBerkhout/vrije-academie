# Waitlist signup returns generic failure

## Goal

Waitlist signup from a sold-out session (e.g. `/ons-aanbod/studiedag-glas-in-lood`) succeeds.

## Why

The modal always mapped API failures to "Aanmelden voor de wachtlijst is niet gelukt." Medusa returned 400 after creating a customer.

## Cause

1. Nested waitlist workflows (`workflowEngine.run` / `runAsStep` / `workflow.run` from inside a parent step) returned before Salesforce Person Account IDs were written. Local Redis is a fake instance, so engine jobs do not complete.
2. Guest signup called `linkAuthIdentityToCustomer` after `createCustomerAccountWorkflow`, which already sets `customer_id` (`Key customer_id already exists in app metadata`).
3. Account create sent `Newsletter__c`, which is not an Account field in this org.

## Fix

`POST /store/events/:handle/waitlist` calls in-process `joinEventWaitlist`: resolve customer, create/link Person Account via the Salesforce service, then upsert `Registration__c` with `Status__c: Wachtlijst`. Session-level signup must send `variant_id`.
