# Fix local Postfix STARTTLS OTP send

## Goal

Find the correct way to send via the local Postfix service without Nodemailer rejecting the self-signed STARTTLS cert.

## Finding

Local Postfix is already the right mail service. Do not replace it with SendGrid.

Staging Postfix (`inet_interfaces=localhost`, `mynetworks=127.0.0.0/8`, OpenDKIM milter, empty `relayhost`) accepts plaintext SMTP from Medusa. It also advertises STARTTLS with Ubuntu snakeoil cert (`/etc/ssl/certs/ssl-cert-snakeoil.pem`).

Nodemailer still upgrades to STARTTLS when `secure=false` if the server offers it. Node then rejects the snakeoil cert → OTP mail fails.

Fix in Medusa, not Postfix: pass `ignoreTLS: true` to nodemailer for loopback (`127.0.0.1` / `localhost`), optionally via `SMTP_IGNORE_TLS`. Then deploy and reload. Do not use `NODE_TLS_REJECT_UNAUTHORIZED=0`.
