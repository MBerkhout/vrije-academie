# Set Audience Player env on staging

## Goal

Put Audience Player OAuth credentials on staging Medusa so /va-thuis/art-nouveau preview plays.

## Steps

1. SSH as medusa user
2. Upsert AUDIENCE_PLAYER_CLIENT_ID / SECRET (and optional PROJECT_ID / PREVIEW_EMAIL) in ~/app/medusa/.env
3. pm2 startOrReload ecosystem.config.cjs
4. Smoke-test preview-playback + browser play

## Resolution / Ergebnis

Done on 2026-09-21. Staging `~/app/medusa/.env` had no `AUDIENCE_PLAYER_*` keys. Copied client id/secret plus project id, API URL, preview email, and public embed host from local `medusa/.env`. Reloaded PM2 cluster (`startOrReload --update-env`).

`GET /store/events/art-nouveau/episodes/1-1/preview-playback` now returns 200 with `articleId` 339, `assetId` 200, duration 91s, and a token. Browser check on https://v2.vrijeacademie.nl/va-thuis/art-nouveau: Introductie preview plays (video.js, DASH stream, not paused).
