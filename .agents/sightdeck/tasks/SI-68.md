# Infinite scroll still stops after Back from a product

## Goal

After a visitor scrolls a listing, opens a product, and uses Back, they must be able to infinite-scroll through the rest of the result set — not only a short extra stretch.

## Notes

Previously extra pages were wiped when the first page was resent (`keepLoadedListingItems`). Confirm with runtime logs whether that still happens, or whether load-more / the sentinel / scroll restore is what stops further pages.
