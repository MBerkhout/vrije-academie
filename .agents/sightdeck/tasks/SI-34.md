# VAthuis PLP filter facets from catalog

## Goal

With **Beschikbaarheid → VAthuis** on Ons aanbod, **Categorie** and **Docent** match the VA Thuis catalog (`/va-thuis/ons-aanbod`), not the two leftover PLP `pre_recorded` rows.

## Why

`GET /store/events` built category/docent facets from the PLP snapshot link tables. Merged VAthuis rows carry `categories` / `docenten` on the product, but those links are missing, so the sidebar only showed Geschiedenis and Literatuur.

## Approach

Count category and teacher facets from listing-row taxonomy (same source as `GET /store/vathuis`).
