# Keep manual street/city on profile save

## Goal

A user who clicks Wijzigen and edits straat/plaats on `/mijn-account/gegevens` must keep those values after Gegevens opslaan. PDOK must not overwrite them on save, refresh, or the same pattern on checkout/registration.

## Cause

Save stored the manual straat/plaats. Hydrate then set `manualAddress=false` because a house number exists. `usePdokAddressLookup` cleared street/city and filled PDOK (`Torenallee` / `Eindhoven` over `Torenstraatje` / `Mooistestad`). Same hook on checkout and `/login`.

## Fix

Skip PDOK overwrite when straat and plaats are already filled for the current postcode + huisnummer. Lookup still runs when those two fields change, or when straat/plaats are empty.

## Surfaces

- Account persoonlijke gegevens (`AccountGegevensForm`)
- Checkout guest/known details (`CheckoutLoginForm`)
- Registration (`LoginForm`) — same PDOK hook
