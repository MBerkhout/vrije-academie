# AND city with month/dagdeel on the same session

## Goal

Ons aanbod (and search + period) should only list a product when **one session** matches every selected time/place filter (city AND month AND/or dagdeel). The card date should be that session, not a different month.

## Why

City, day-part and period are independent product-level checks today, so Amsterdam in the morning + Utrecht in the evening still matches Amsterdam + avond, and a September filter can still show an October “Vanaf” date.
