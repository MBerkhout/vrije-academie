# Fix workshop card hover image bounce

## Goal
Keep the hover zoom on homepage/column workshop product-card thumbnails, without the image shifting or bouncing to the right.

## Context
`ColumnsBlock` `productCards` rows use `next/image` `fill` plus `group-hover:scale-[1.02]`. Scaling the absolutely positioned `fill` img (`left/right/top/bottom: 0`) interpolates from `transform: none` and can origin-shift horizontally.

## Approach
Clip the thumb in an overflow-hidden frame and apply `scale` to an inner `absolute inset-0` wrapper that already has `scale-100` + `origin-center`.
