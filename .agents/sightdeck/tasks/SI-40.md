# Tighten search so Colleges Iran does not pull unrelated hits

## Goal

`?q=Colleges Iran` should return Colleges Iran (and close Iran matches), not every college series.

## Why

`multi_match` used OR + `fuzziness: AUTO` on all fields including autocomplete ngrams. "Colleges" alone matched the whole college catalog.

## Approach

Require all query terms (`operator: and`, `cross_fields` on title/handle/taxonomy). Keep edit-distance 1 typos on title/handle only, not on body or autocomplete ngrams.
