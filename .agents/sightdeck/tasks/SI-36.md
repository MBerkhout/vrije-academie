# Prevent mobile input zoom on field focus

## Goal

Tapping an input, textarea or select on a phone should not zoom the page.

## Why

iOS Safari (and some Android browsers) zoom focused form controls when the computed font-size is below 16px. Site fields inherit or set `text-sm` (14px).

## Approach

Force `font-size: 1rem` (16px) on text-entry form controls on touch / small viewports in `globals.css`. Do not disable pinch-zoom via the viewport meta tag.
