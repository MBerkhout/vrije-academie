# Show real VAthuis count on Ons aanbod

## Goal

The unfiltered **Beschikbaarheid → VAthuis** facet shows the VAthuis catalog size, not `1`.

## Why

`GET /store/events` injected `pre_recorded` only when the PLP snapshot had none. One leftover `pre_recorded` row made the overview display **VAthuis 1**.

## Approach

Count unique `pre_recorded` products after merging the VAthuis snapshot into the current list, then inject that count. Keep default results exclusive of VAthuis.
