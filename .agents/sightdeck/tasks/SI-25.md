# Keep VAthuis as an in-page Ons aanbod filter

## Goal

The **Beschikbaarheid → VAthuis** option stays on Ons aanbod (and Agenda) as a normal checkbox. It must not navigate to `/va-thuis/ons-aanbod`. Checking it filters the current listing to VAthuis / `pre_recorded` products.

## Why

Leaving the page was the wrong interaction. VAthuis should behave like Online / Op locatie.

## Approach

- Remove the special link and `?delivery_type=pre_recorded` redirects.
- Merge the VAthuis listing snapshot into `GET /store/events` when `delivery_type` includes `pre_recorded`, so the filter returns products instead of an empty grid.
- Keep default Ons aanbod (no delivery filter) exclusive of VAthuis.
