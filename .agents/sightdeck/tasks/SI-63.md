# Fix PDP mobile gallery swipe

On the product detail page mobile image carousel, chevron arrows change slides correctly. Swiping or dragging the gallery does not.

## Cause

Runtime on a 390px PDP (`studiedag-kunstgeschiedenis-in-1-dag`):

- Last slide needs `scrollLeft` **662** to snap flush left; `maxScroll` is only **513** (`canAlignLast: false`). CSS `snap-mandatory` then yanks back from the last image.
- Pointer-up called `scrollToIndex(start+1)` while an 80ms post-scroll snap also ran (`pointer-next` then `snap-nearest` in the same gesture). Native `scrollDelta` stayed `0` during the pointer path.

## Fix

Trailing spacer (`40% + 6px`) so the last 60% slide can snap. Native CSS snap for swipe; mouse drag writes `scrollLeft`. No JS snap-on-scroll / pointer-up `scrollToIndex`.
