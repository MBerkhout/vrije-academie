# Checkout back link should go to cart

## Goal

The checkout shell link **Terug naar winkelwagen** must go to `/winkelwagen`, not to Ons aanbod.

## Cause

`checkout/layout.tsx` used `cart.continueShoppingUrl` (Sanity “Continue shopping URL”, default PLP). That field is for the cart’s **Verder winkelen** link, not for leaving checkout.

## Change

Hard-code `/winkelwagen` for the checkout back link. Leave `continueShoppingUrl` on the cart page.
