# Listing Back jumps to top before the product card

## Goal

When a visitor opens a product from a listing and uses Back, the listing should appear already at the opened card — no flash of the page top.

## Approach

- Save `scrollY` with the existing listing-return token.
- Set `history.scrollRestoration` to `manual` before leaving the listing.
- Restore that offset in `useLayoutEffect` (before paint), then keep applying it briefly so Next.js cannot win a post-navigation scroll-to-top.
- If the card is not in the viewport after the offset restore, fall back to `scrollIntoView`.
