# Medusa email / SendGrid staging

## Question

Is transactional mail (OTP and other Medusa emails) ready, and can it be switched on for staging?

## Answer (code)

Medusa already uses `@medusajs/notification-sendgrid` when `SENDGRID_API_KEY` is set in `medusa/.env`. Without the key, OTP codes are logged to stdout only.

Wired senders:

- OTP login / set-password (`template: customer-otp`)
- Gift-card purchase (`template: gift-card-purchased`)

Not sent by Medusa: order confirmations, waitlist, admin-generated OTP (shown in Admin).

## Staging

Yes: add `SENDGRID_API_KEY` and `SENDGRID_FROM` to `~/app/medusa/.env`, then PM2 reload. Sender must be verified in SendGrid. Not currently listed as a required staging secret in `docs/DEPLOYMENT.md`.

## Caveat

SendGrid provider sends `content.html`, not `content.text`. Current OTP/gift-card payloads only set `text`, so real sends may fail until HTML is passed (OTP then falls back to logs).
