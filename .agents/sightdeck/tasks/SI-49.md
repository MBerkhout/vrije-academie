# Reduce hero top-panel right padding

The text column uses uniform padding (`p-4 sm:p-6 lg:p-6`). Right padding should be `pr-2` (8px) at all breakpoints. Repeat `sm:pr-2` and `lg:pr-2` after the shorthand padding classes so they are not overwritten.
