# Set staging PLP revalidate secrets

## Goal

Medusa can POST `https://v2.vrijeacademie.nl/api/revalidate/plp` with a Bearer secret that matches frontend `REVALIDATE_SECRET`. Do not print the value. Do not reuse Studio or webhook secrets.

## Resolution / Ergebnis

Matching 64-char PLP secret (sha256_12=`5894ef25b9dc`) written to:

- staging frontend `REVALIDATE_SECRET` + PM2 reload
- staging Medusa `STOREFRONT_REVALIDATE_SECRET` + `STOREFRONT_REVALIDATE_PLP_URL=https://v2.vrijeacademie.nl/api/revalidate/plp` + PM2 reload
- local `frontend/.env` and `medusa/.env` (`STOREFRONT_REVALIDATE_PLP_URL=http://localhost:3000/api/revalidate/plp`)

It does not equal the Studio or webhook secrets. Authenticated `POST /api/revalidate/plp` returned 200 `{ revalidated: true, tags: ["plp-default","agenda-default"] }`; no-auth returned 401.
