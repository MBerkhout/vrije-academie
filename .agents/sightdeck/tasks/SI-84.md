# PDP waitlist and bijna-vol CTA styling

## Goal

On PDP session rows, the **Wachtlijst** button matches **Direct inschrijven** in width, uses `#bfbfbf` with hover `#4c4c4c`, and **Bijna vol** uses `#f7373d` with hover `#E0282E`.

## Why

Follow-up to SI-43 (Volgeboekt → Wachtlijst). The shorter label made the sold-out CTA narrower than Direct inschrijven. Joline asked for matching width plus those two status colours.

## Approach

- Shared min-width on session CTAs so Wachtlijst / Bijna vol / Direct inschrijven align.
- Waitlist CTA: `#bfbfbf` / hover `#4c4c4c` (dark text, white on hover).
- Almost-full session CTA (qty > 0 and ≤ low-stock threshold): label **Bijna vol**, `#f7373d` / hover `#E0282E`, still enrols.
