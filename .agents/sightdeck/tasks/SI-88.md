# Set staging Studio revalidate secret

## Goal

`SANITY_STUDIO_REVALIDATE_SECRET` exists on staging frontend, in GitHub Actions, and locally. Do not print the value. Do not reuse the webhook HMAC.

## Out of scope

- Medusa PLP `STOREFRONT_REVALIDATE_SECRET`
- Deploying hosted Studio (GitHub secret is set; next `sanity deploy` bakes it)

## Resolution / Ergebnis

Same 64-char secret (sha256_12=`08c346320037`) written to:

- staging `/var/www/frontend/app/frontend/.env` + PM2 reload
- GitHub Actions `SANITY_STUDIO_REVALIDATE_SECRET`
- local `frontend/.env` and `sanity/.env` (gitignored)

It does **not** equal the webhook HMAC. Authenticated `POST /api/revalidate/studio` on staging returned 200 `{ revalidated: true, path: "/" }`.
