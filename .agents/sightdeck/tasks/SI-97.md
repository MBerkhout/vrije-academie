# Webhook creates product group but not variants

## Finding

`lezing-over-het-leven-van-een-webbouwer1` (`prod_01M37KJSMND07EJWFBTMHEAPWM`, Salesforce `a059X00000pdcCvQAI`) was imported by two successful `vaProductgroup__c` update webhooks at 17:03–17:04 UTC.

Salesforce has two future child sessions, both with **Zichtbaar op Website** unchecked (`Visible_On_Website__c = false`):

- `a049X00000PWoHpQAL` — Alkmaar, 2026-10-25 13:00
- `a049X00000PWoMfQAL` — Arnhem, 2026-10-28 09:00

The importer skips hidden children and stores only the placeholder variant `sf-group-a059X00000pdcCvQAI` (`salesforce_visible_on_website: false`). The PDP therefore shows no sessions.

## Follow-up

`vaProduct__c` webhooks read `Productgroup__c`, but the API name is `ProductGroup__c`, so child webhooks cannot resolve the parent (`Could not resolve parent product group for course product`). Checking the child box only re-imports variants when the product group webhook also runs, or after that lookup is fixed.
