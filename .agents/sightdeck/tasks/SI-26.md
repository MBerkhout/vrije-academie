# PLP product-type plurals from Sanity

## Goal

1. Restore the category filter heading to **Categorie**.
2. Keep the PDP record-type badge as the singular Salesforce name (**Reis**).
3. Show a plural on the PLP (filter, chips, `/ons-aanbod/reis` title), default **Reizen**, editable in General Settings.

## Approach

Add `generalSettings.plp.productTypePlurals` (reis, studiedag, wandeling, workshop). Frontend falls back to `Reizen` for reis when CMS is empty. Product-type filter group stays **Soort activiteit**.
