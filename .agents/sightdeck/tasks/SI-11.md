# Reset does not clear filters on detail pages

## Goal

On a path-scoped PLP such as `/ons-aanbod/studiedag`, pressing **Reset** (and **Wis alle filters**) should remove all filters and return to `/ons-aanbod`.

## Memory

`clearAll` in `PlpFilterSidebar` and `PlpActiveChips` currently does `router.push(basePath)` when the listing is category- or product-type-scoped. That keeps the path filter (e.g. Studiedag) in place.

## Steps

1. Confirm the reset/clear handlers and existing redirect tests.
2. Change clear-all to navigate to `/ons-aanbod` for path-scoped PLPs.
3. Cover with tests and update listing docs.
4. Verify in the browser.

## Resolution

`clearAll` stayed on the path URL (`/ons-aanbod/studiedag`), so the type/category filter never left. Reset, Wis alle filters, and empty-state clear now go to `/ons-aanbod` via `resolveClearAllHref`. Agenda and VA Thuis catalog stay on their own listing.
