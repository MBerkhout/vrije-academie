Medusa `medusa build` fails on staging because `collapseDuplicateGiftCardCredits` filters `cart.credit_lines` while the cart is `Record<string, any>`. The callback parameter is then an implicit `any` under `noImplicitAny`.

`stripGiftCardCredits` already assigns `credit_lines` to `any[]` before filtering. Do the same here so the callback is typed and the backend compile succeeds.
