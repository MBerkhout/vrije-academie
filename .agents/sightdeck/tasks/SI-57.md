# Medusa SMTP notification provider

## Goal

Medusa can send OTP and cadeaubon mail over SMTP (server or authenticated relay). SendGrid stays as fallback. Mail bodies include HTML so SendGrid also works.

## Approach

- Custom notification provider (`src/providers/smtp`) using nodemailer.
- Env: `SMTP_HOST` (enables SMTP), `SMTP_PORT`, `SMTP_SECURE`, `SMTP_USER`, `SMTP_PASS`, `SMTP_FROM`.
- SMTP wins when both SMTP and SendGrid are set. Neither set → log OTP to stdout.
- Shared `emailContent()` adds HTML from plain text.
- Docs: CUSTOMER_AUTH, GIFT-CARDS, DEPLOYMENT, `.env.template`.

## Shipped

SMTP provider + SendGrid fallback, HTML bodies on OTP and cadeaubon. Staging: set `SMTP_*` in `~/app/medusa/.env` and reload PM2. Real SMTP send not tested (no server credentials in this session).
