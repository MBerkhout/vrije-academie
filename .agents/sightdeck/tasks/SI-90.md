# Rondleiding Paleis op de Dam shows lezing not Wandeling

`GET /store/events/rondleiding-paleis-op-de-dam`:

- `product_type` = **Rondleiding** (Salesforce developer name)
- `record_type` = **lezing** (unknown EventGroup fallback)

Salesforce has **Rondleiding** and **Wandeling** as separate record types (local catalog ~565 vs ~289). Paleis op de Dam is a guided palace tour, not a walking tour.

The PDP only promoted reis / studiedag / wandeling / workshop from `product_type`. Rondleiding was missing, so the chip fell back to EventGroup **lezing**.

Fix: add **Rondleiding** as a Soort activiteit type (badge **Rondleiding**, landing `/ons-aanbod/rondleiding`, listing plural **Rondleidingen**). Do not map it to Wandeling.
