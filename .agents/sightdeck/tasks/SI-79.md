# Mobile agenda layout and date filter

## Goal

On `/agenda` at mobile widths:

1. The filter drawer opens with the day-picker (agenda date filter) first and expanded.
2. Each occurrence card stacks: date/time, then title, then location, then the status button.

## Why

The calendar is desktop-only today (`AgendaFilterSidebar` skips it when `mobileOnly`). Mobile rows still use a three-column grid, so date, title, and CTA compete for horizontal space.

## Approach

- Pass the `AgendaDayPicker` into the shared mobile drawer as the first collapsible group, default open.
- Below `sm`, render `AgendaRow` as a vertical card instead of a date | title | CTA grid. Keep the current four-column row from `sm` up.
