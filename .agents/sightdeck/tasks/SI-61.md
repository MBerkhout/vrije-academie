# Enable publishing Sanity categories

## Goal

Editors can publish mirrored `category` documents in Sanity Studio so editorial thumbnails (`image`) and other Studio-owned fields go live.

## Why

`mirroredDocumentActions` currently strips all default actions for `category` and `docent` (Open in Medusa only). Image/title/SEO edits stay as unpublished drafts, so homepage tiles and search thumbs never update from Studio.

Products already keep Publish/Discard plus Open in Medusa.

## Approach

1. Treat `category` like `product` in document actions (keep defaults + Open in Medusa). Leave `docent` action-minimal.
2. Revalidate homepage, VA Thuis landing, and the category PLP when a category is published, so tile images do not wait on the 60s ISR window.
3. Update Sanity/Medusa/deployment docs.

## Out of scope

- Creating categories from Studio (still blocked).
- Making `docent` publishable.
