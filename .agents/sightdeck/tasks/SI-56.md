# Vaak gezocht item not showing

## Symptom

User added a Vaak gezocht item in Sanity and does not see it in the storefront search overlay.

## Sanity state (2026-09-21T15:26Z)

Published `generalSettings.header.popularSearches`:

- Label: `Dit wordt super veel gezocht`
- Link: `/hallo-mick`

No remaining draft.

## Cause

The item is published. Local header settings are cached for 60s (no Sanity webhook on localhost). After a hard refresh, header Zoek with an empty field shows **Vaak gezocht** → `Dit wordt super veel gezocht`. Typing ≥2 characters hides the list. Ons aanbod inline search does not show these shortcuts.
