# Password field eye toggle

## Goal

Let users show or hide the typed password with an eye button on storefront password fields.

## Surfaces

- `/login` — login password and register password / confirm
- `/checkout/inloggen` — known-account password
- `/mijn-account/gegevens` — change/set password modal

## Approach

Shared toggle in `Input` and `ValidatedInput` when `type="password"`. Wrap the remaining raw login password input the same way. Dutch `aria-label`s for show/hide.

## Out of scope

- Medusa admin customer-auth panel
