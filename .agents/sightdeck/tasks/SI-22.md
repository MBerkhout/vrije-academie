# Text block title/subtitle divider

Pages such as `/magazine-aanvragen` currently use two Text blocks (H1 + H3 in Portable Text) as a page header. Editors should set heading + subtitle on one Text block and optionally draw a line between them.

## Approach

- Add `subtitle` and `showTitleDivider` to the Text block heading fieldset.
- Render subtitle under the heading; when the divider is on, insert an `<hr>` between them.
- Cover with TextBlock tests and document in Sanity + frontend block docs.
