# Cart header row too tall

The desktop cart column header used an empty 4:3 box (`aspect-[4/3] h-20`) so "Product" lines up with the title column. That box is 80px tall, the same height as the thumbnails, so the header row is as tall as an image. "Aantal personen" and "Prijs" sit in a stretched column and end up vertically centered, below "Product".

Fix: keep a width-only spacer (`5rem * 4/3`, matching `md:h-20` thumbnails) and align the three labels on one baseline.
