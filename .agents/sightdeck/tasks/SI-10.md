# Why wandeling Bourtange is labelled Lezing

Staging: https://v2.vrijeacademie.nl/ons-aanbod/wandeling-vesting-bourtange

## Question

Why does Wandeling Vesting Bourtange show a Lezing badge when it is a walking tour?

## Resolution / Ergebnis

Not a past-session issue. Two fields disagree:

- `product_type` = **Wandeling** (Salesforce developer name `Wandeling`, used by Soort activiteit)
- `record_type` = **lezing** (EventGroup)

`mapSalesforceRecordType()` only knows collegereeks / lezing / excursie / studiedag / vathuis. Unknown names, including `Wandeling`, fall through to `"lezing"`.

`PdpHeader` renders `event.record_type` as the extra chip, so the PDP shows **lezing**. The chip links to `/ons-aanbod?record_type=lezing`.
