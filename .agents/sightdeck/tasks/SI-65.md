# Fix implicit any on listCustomerOrders filter

## Goal

The Next.js type check must pass for `listCustomerOrders` in `frontend/src/lib/commerce/medusa-client.ts`.

## Why

`medusa.store.order.list` types `orders` loosely enough that `.map().filter()` leaves the filter callback parameter as implicit `any` under `noImplicitAny`.

## Approach

Type the mapped list as `Order[]` and pass `isOrderVisibleInAccount` as the filter predicate so the callback is explicitly typed.
