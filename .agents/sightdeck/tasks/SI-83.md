# Always show Vanaf on listing product cards

## Goal

On Ons aanbod product tiles (`PlpEventCard`), always show:

- **Vanaf 22 sep 2026** instead of a bare date
- **Vanaf €345** instead of **Voor €345**

## Scope

Listing cards only (`PlpEventCard` on `/ons-aanbod` and other reuse of that card). PDP booking panel keeps Voor vs Vanaf based on uniform vs varying session prices.

## Approach

- Date: always prefix with **Vanaf** when a date is shown (not only when there are multiple session dates).
- Price: always use the **Vanaf** copy when a price is shown.
